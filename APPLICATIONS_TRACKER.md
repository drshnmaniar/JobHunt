## 4. Status Transition Guide

When you complete an action or receive an update, tell the agent (or update manually):
- *"Mark Stripe as applied today"* &rarr; Status becomes `APPLIED`, adds submission timestamp, triggers outreach reminder.
- *"Scheduled recruiter screen with Stripe for Friday"* &rarr; Status becomes `SCREENING`, adds interview prep checklist.
